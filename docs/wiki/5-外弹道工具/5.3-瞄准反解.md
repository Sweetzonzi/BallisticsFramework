# 5.3 瞄准反解

> **问题**："从 A 点以初速 s 射击 B 点，枪口该指向什么方向？（抬高多少度？）"

瞄准反解（firing angle solve）是最常见的实战场景——AI 炮塔需要自动瞄准、玩家需要弹道指示器给出瞄具参考、炮兵需要计算射击诸元。在有重力和阻力的弹道中，枪口不能直接指向目标——必须向上抬高。抬高多少取决于距离、初速、弹道参数和发射者自身的运动速度。

解算器采用**二分搜索**在仰角空间中求解——每轮试一个仰角、做一次正解、看弹丸最近接近目标有多远、根据结果是"打远了"还是"打近了"调整搜索区间、重复直到收敛。

---

## FiringSolution —— 反解结果

```java
FiringSolution(Vec3 direction, float flightTime, Vec3 terminalVelocity,
               boolean isHighArc, int iterations)
```

| 字段 | 说明 |
|------|------|
| `direction` | 出射方向单位向量（世界坐标），可直接作为弹丸的初速度方向 |
| `flightTime` | 预计飞行时间（s），用于引信延迟、动画同步等 |
| `terminalVelocity` | 命中目标时的末速度（m/s）——可直传 `BFDamageContext.hitVelocity` |
| `isHighArc` | `true` = 高抛弹道（仰角 > 45°），`false` = 平射弹道（仰角 < 45°） |
| `iterations` | 二分搜索的迭代次数——值越小收敛越快（但差距可能稍大） |

### 单解与双解

初速充足时，一个目标有**两个**解（平射和高抛）：

```
          高抛弹道（仰角 > 45°）
         ╱╲
        ╱  ╲        ← 弹丸飞得很高然后落下，飞行时间长
       ╱    ╲
──────▶──────▶──────  ← 目标位置
  发射点  平射弹道（仰角 < 45°）
         弹丸走低弧线，飞行时间短
```

- **平射解**（`isHighArc=false`）——弹丸走较低弧线，飞行时间短，适合对直线目标快速射击。这是大多数场景的首选。
- **高抛解**（`isHighArc=true`）——弹丸走高抛物线，飞行时间长，适合跨越障碍物（如山脊、城墙）射击掩体后的目标。

初速刚好是"能命中"的最小值时，两解收敛为一点（临界弹道），仅返回平射等效解。初速不足时返回空列表——无论哪个仰角弹丸都无法到达目标。

## 发射者速度：移动平台射击

如果你在移动的载具上射击，弹丸的初速度是世界速度 = 方向 × 标量 + 发射者速度：

```java
// 内部实现
Vec3 worldVelocity = direction.scale(speed).add(shooterVelocity);
```

你需要在调用反解时传入发射者的速度矢量：

```java
Vec3 shooterVelocity = vehicle.getDeltaMovement();  // 载具的当前速度
List<FiringSolution> solutions = /* 解算器 */.solveFiringAngle(
    start, target, speed,
    shooterVelocity,   // ← 不传 Vec3.ZERO
    // ...其余参数
);
```

发射者速度的值可以从实体取：`entity.getDeltaMovement()`（返回的单位也是 m/tick，与 MC 模型的入参一致；拟真模型下如果你 m/s 的 speed 与 m/tick 的 shooterVelocity 混合使用会有速度单位不一致的问题——使用前请确认单位对齐，或者将 shooterVelocity 也乘以 20 转为 m/s）。

> **注意**：MC 模型的反解入参使用 m/tick，而拟真模型使用 m/s。如果你在拟真模型下想传入发射者速度 `entity.getDeltaMovement()`，需要先 `×20` 转换为 m/s。如果你不传发射者速度（传 `Vec3.ZERO`），则视为从固定平台射击。

## MC 原版模型的反解

### 使用方式

```java
// 最简调用——箭矢参数，固定平台射击
List<FiringSolution> solutions = MinecraftTrajectory.arrowFiringAngle(
    shooterPos, targetPos,
    6.0f,           // 初速标量 (m/tick)
    Vec3.ZERO,      // 发射者速度（固定平台传零向量）
    200             // maxTicks
);

if (solutions.isEmpty()) {
    // 初速不足，任何仰角都无法命中——需要增大初速或靠近目标
    return;
}

FiringSolution lowArc = solutions.get(0);   // 平射解
// lowArc.direction() → 直接设为弹丸的 deltaMovement 方向
```

可用的便捷方法：`arrowFiringAngle`、`snowballFiringAngle`、`fireballFiringAngle`。

### 通用版（自定义弹道参数）

```java
List<FiringSolution> solutions = MinecraftTrajectory.solveFiringAngle(
    start, target, speed, shooterVelocity,
    0.97f, 0.96f,     // dragH, dragV
    -0.03f,            // gravity
    150,               // maxTicks
    0.01f              // angleEpsilon —— 仰角收敛阈值 (弧度)，0.01 ≈ 0.57°
);
```

### angleEpsilon —— 精度与性能的平衡

`angleEpsilon` 控制仰角收敛精度。推荐值 `0.01`（约 0.57°），对于大多数射程来说，±0.5° 的角度误差对应的落点偏差在 1 米以内。如果你需要更精确的瞄准（如 500 米以上的远距离狙击），可以降为 `0.005`，但二分搜索的迭代次数会增加。

## 拟真模型的反解

拟真模型的反解与 MC 原版方法签名不同——参数通过 `BallisticConfig` 封装而不是散列，并额外需要一个 `DensityFunction`。

```java
BallisticConfig config = BallisticConfig.fromExtensions(exts, 0.35f, 0.8f, 0.05f, 200);

List<FiringSolution> solutions = RealisticTrajectory.solveFiringAngle(
    shooterPos, targetPos,
    1500f,                     // 初速 (m/s) —— 注意全 SI 单位
    shooterVelocity,            // 发射者速度 (也应是 m/s)
    config,
    DensityFunction.MC_OVERWORLD,
    0.01f                       // angleEpsilon
);
```

### 初速不足的判断

如果 `solutions.isEmpty()`，说明初速标量不足——即使是最高仰角弹丸的射程也到达不了目标。此时有两种选择：

1. **增大初速**——如果初速可调（如坦克炮的不同弹种），选择更高初速的弹种
2. **靠近目标**——如果初速不可调，AI 或玩家需要移动到更近的距离

你可以通过预判来确定需要的最小初速：

```java
// 二分搜索"刚好能命中"的最小初速
float vLow = 100f, vHigh = 3000f;
for (int i = 0; i < 20; i++) {
    float vMid = (vLow + vHigh) / 2f;
    var sols = RealisticTrajectory.solveFiringAngle(
        start, target, vMid, Vec3.ZERO, config, density, 0.01f);
    if (sols.isEmpty()) vLow = vMid; else vHigh = vMid;
}
float minRequiredSpeed = vHigh;
```

## 退化路径

当弹道参数满足退化条件时，反解走 O(1) 或简化路径而非完整二分搜索：

| 条件 | 反解方式 | 说明 |
|------|------|------|
| g=0, 无阻力 | 方向直接指向目标 | 匀速直线——取 diff.normalize() 即可，O(1) |
| g≠0, 无阻力 | 抛物线解析仰角公式 | `θ = atan((s² ± √Δ) / (g·d))`——数学精确，不二分搜索 |
| g=0, 有阻力 | 沿目标方向一维搜索 | 弹丸沿固定方向减速，仅搜索标量而非仰角 |
| 其他 | 完整二分搜索 | [0°, 45°] 搜索平射解，[45°, 90°] 搜索高抛解 |

退化判定在方法入口完成，仅一次浮点比较，零可察觉开销。

## 高抛弹道的特殊用途

高抛解不仅适合跨越障碍物——在特定战术场景中有独特价值：

| 场景 | 为什么用高抛 |
|------|------------|
| 攻城/攻坚 | 弹丸从上方落下攻击顶部装甲（顶部通常较薄） |
| 炮兵曲线射击 | 弹丸越过山脊或城墙攻击掩体后的目标 |
| 延时抵达 | 如果你需要"等几秒再命中"（协同其他武器的攻击时间窗口） |
| 低速弹丸 | 初速刚够命中时，高抛解和平射解收敛——此时选哪个都差不多 |

高抛解的飞行时间显著长于平射解——引信延迟、视觉效果同步等方面需要考虑到。

## 从反解结果发射弹丸

拿到 `FiringSolution` 后，如何真正把弹丸发射出去？

### MC 原版弹射物

```java
FiringSolution sol = solutions.get(0);

// 方式 A：用出射方向设置箭矢速度
arrowEntity.setDeltaMovement(
    sol.direction().scale(speed)   // 从 FiringSolution 取方向，乘初速标量
        .add(shooterVelocity)       // 加上发射者速度 = 真实世界速度
);

// 方式 B：用出射方向设置自定义弹丸的旋转
float yaw = (float) Math.toDegrees(
    Math.atan2(-sol.direction().x, sol.direction().z));
float pitch = (float) Math.toDegrees(
    -Math.asin(sol.direction().y));
entity.setYRot(yaw);
entity.setXRot(pitch);
```

### 自定义物理弹丸（拟真模型）

```java
FiringSolution sol = solutions.get(0);
Vec3 worldVel = sol.direction().scale(speed).add(shooterVelocity);
// worldVel 就是最终初速度（m/s），直接设给自定义弹丸的 velocity 字段
customProjectile.velocity = worldVel;   // 你的自定义弹丸的速度变量
customProjectile.pos = start;
```

## 完整示例：AI 炮塔自动瞄准

以下是 AI 炮塔自动瞄准的完整代码片段。炮塔每 10 tick（0.5 秒）重新解算一次，以应对目标移动和炮塔自身移动。

```java
// 炮塔 AI tick 方法中
if (this.tickCount % 10 == 0) {
    // 获取目标和炮塔自身位置与速度
    Vec3 targetPos = this.currentTarget.position();
    Vec3 targetVel = this.currentTarget.getDeltaMovement();
    Vec3 myPos = this.position();
    Vec3 myVel = this.getDeltaMovement();

    // 拟真模型反解
    BallisticConfig config = BallisticConfig.fromExtensions(
        this.ammoExts, 0.35f, 0.8f, 0.05f, 200);
    List<FiringSolution> solutions = RealisticTrajectory.solveFiringAngle(
        myPos, targetPos,
        this.muzzleVelocity,        // m/s
        myVel,                       // 炮塔自身速度 (m/s)——考虑移动平台
        config,
        DensityFunction.MC_OVERWORLD,
        0.01f
    );

    if (!solutions.isEmpty()) {
        FiringSolution sol = solutions.get(0);
        this.aimDirection = sol.direction();   // 转塔向这个方向
        this.estimatedFlightTime = sol.flightTime();  // 用于引信
    }
}

// 射击时
if (this.canFire() && this.aimDirection != null) {
    Vec3 worldVel = this.aimDirection.scale(this.muzzleVelocity).add(this.getDeltaMovement());
    spawnProjectile(this.position(), worldVel);
}
```
